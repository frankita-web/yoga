# Prana · Chakras, Ashtanga y Savasana

Página en Next.js (App Router) con:

- **Silueta con los 7 chakras**: al pasar el cursor (o tocar) cada chakra se ilumina en su color y muestra su nombre, ubicación, elemento y mantra.
- **Reproductor de Ashtanga**: serie primaria guiada en sánscrito (YouTube), con controles propios.
- **Savasana de 1 minuto**: temporizador con sonido ambiente generado en el navegador y un cuenco al inicio y al final.

```bash
npm install
npm run dev
```
